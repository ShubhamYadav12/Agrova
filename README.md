\# Agrova



\## Digital Operating System for the Farm



Agrova is a farmer-first Farm Intelligence platform designed around the

farmer's real 365-day farm life.



\### Core Philosophy



> Farmer ko technology samajhne ki zarurat nahi —

> technology ko farmer samajhna chahiye.



\### Product Vision



Help the farmer understand what is happening across the farm

and decide what to do next.



\### Core Domains



\- Pashu — Animals

\- Khet — Crops \& Fields

\- Farm Resources

\- Farm Activities

\- Tasks \& Reminders

\- Weather \& Risk

\- Farm Intelligence

\- Farm Economics

\- Conversational Agrova



\### Technology



\- Backend: Java + Spring Boot

\- Frontend: Angular + TypeScript

\- Database: PostgreSQL

\- Database Migration: Flyway

\- Architecture: Modular Monolith



\### Project Status



Project initialization — September 2026.
